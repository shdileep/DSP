# Contributing Guidelines

Thank you for your interest in contributing to the DSP Personal Portfolio project!

## Development Workflow

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shdileep/DSP.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Run build checks:**
   ```bash
   npm run build
   ```

## Coding Conventions

- Write clean, declarative TypeScript and modern React components.
- Use Tailwind CSS for utility-first styling.
- Keep components modular and maintainable.
- Ensure all assets are optimized for fast loading times.

## Submitting Pull Requests

- Create a feature branch for your changes (`git checkout -b feature/amazing-feature`).
- Ensure code builds and lints cleanly without errors.
- Provide a clear and concise description of the changes in your pull request.
