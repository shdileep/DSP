# Changelog

All notable changes to the DSP Portfolio project will be documented in this file.

## [1.0.0] - 2026-08-30

### Added
- **Multi-Layout System:** Support for Executive, Original, Product Studio, and Research Lab layouts.
- **Interactive Apps:** Embedded NextTrip and UjjwalHub interactive PC experiences.
- **AI Pipelines & Chat:** Integrated deep AI chat assistant and RAG pipeline.
- **Modern UI & Animations:** Fluid responsive layouts with Tailwind CSS, Lucide icons, and Framer Motion.
- **Dynamic PDF Resume Generator:** In-browser custom styled resume generator with jsPDF.
